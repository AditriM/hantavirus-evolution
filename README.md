# hantavirus-evolution
Sequence-based phylogenetic analysis and host prediction for hantavirus strains.

## Project Goal
Build a pipeline that:
- Downloads and cleans hantavirus sequences from NCBI Virus
- Builds time calibrated phylogenetic trees per genome segment (M, S, L)
- Identifies genomic sites under positive selection
- Predicts reservoir host genus from sequence using a random forest classifier
- Flags fast-evolving lineages for closer surveillance
- Visualizes all results in a live Streamlit dashboard
- (we don't need all of this by midterm presentations)
